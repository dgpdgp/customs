## Что известно об ASYCUDA (по реальным файлам пользователя)

- Корень `<ASYCUDA>`, без отступов, переводы строк CRLF, пустые элементы `<tag/>`, пустые строковые поля —
  `<tag><null/></tag>`.
- Код товара: `Commodity_code` — 8 цифр, `Precision_1` — 3 цифры (24012035 + 000). На сайте код пишется
  целиком, 11 цифр; промпт велит склеивать эти два элемента. Официальная длина грузинского кода не подтверждена.
- Страны — числовой код ISO 3166 без ведущих нулей + двухбуквенный (76 / BR, 268 / GE); валюта — числовой
  ISO 4217 (840 = USD). Даты в графе 44 — M/D/YY (5/21/26).
- Чистый бланк из ASYCUDA уже содержит декларанта (брокера) и способ оплаты «ნაღდი».
- Пример пользователя — вывоз со склада (процедура 7474, блок `<Prev_decl>`), таможня 11111.
- **Неизвестно**: пересчитывает ли ASYCUDA курс и стоимость при импорте; нужны ли документы графы 44
  в каждой позиции; примет ли `Precision_1` из 2 цифр. Неуверенные места кода — ANSWERS.md, п. 2б.
- Реальных файлов пользователя в репозитории нет (там данные клиентов). Нужны — попросить заново.
