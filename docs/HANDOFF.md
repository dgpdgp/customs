## Последняя проблема и что сделано

Пользователь импортировал в ASYCUDA XML с сайта: импорт «успешен», но бланк пустой и ошибка
**«Statistical value must be greater than 0»**.

- Причина (доказана тестом): обычный экспорт заполняет только шаблоны с `{{ … }}`. В XML, выгруженном из ASYCUDA,
  плейсхолдеров нет — сайт возвращал файл без изменений (лишь переводы строк CRLF → LF), новые товары не попадали.
- Формат и версия файлов сайта и ASYCUDA совпадали (те же элементы в том же порядке) — дело было не в версии.
- Исправление (5dd04f6): файл из ASYCUDA — основа; всё вне `<Item>` сохраняется байт в байт, позиции и итоги
  строятся заново, курс можно ввести на странице задачи. Проверено на реальном файле пользователя:
  с теми же данными выход идентичен оригиналу, с новыми — меняются только товары, итоги и номера документов.
- **Импорт в саму ASYCUDA не проверен** (у Claude её нет). Ждём результат от пользователя.

## Что известно об ASYCUDA (по реальным файлам пользователя)

- Корень `<ASYCUDA>`, без отступов, переводы строк CRLF, пустые элементы `<tag/>`, пустые строковые поля —
  `<tag><null/></tag>`.
- Код товара: `Commodity_code` — 8 цифр, `Precision_1` — 3 цифры (24012035 + 000). На сайте код пишется целиком,
  11 цифр. Настройка «Цифр в коде ТН ВЭД» по умолчанию 10 — для Грузии, вероятно, нужно 11
  (по файлам ASYCUDA; официально не подтверждено).
- Страны — числовой код ISO 3166 без ведущих нулей + двухбуквенный (76 / BR, 268 / GE); валюта — числовой
  ISO 4217 (840 = USD). Даты в графе 44 — M/D/YY (5/21/26).
- Чистый бланк из ASYCUDA уже содержит декларанта (брокера) и способ оплаты «ნაღდი».
- Пример пользователя — вывоз со склада (процедура 7474, блок `<Prev_decl>`), таможня 11111.
- **Неизвестно**: пересчитывает ли ASYCUDA курс и стоимость при импорте; нужны ли документы графы 44
  в каждой позиции; примет ли `Precision_1` из 2 цифр.
- Реальных файлов пользователя в репозитории нет (там данные клиентов). Нужны — попросить заново.

## Сервер (ведёт локальный Claude пользователя)

- Домашний сервер: Docker + Caddy (HTTPS). Адрес сайта и папку развёртывания пользователь сообщит сам —
  в этот публичный файл они намеренно не записаны.
- На сервере есть скрипты вне репозитория: `set-api-key.sh` (скрытый ввод ключа), `create-user.sh`, `update.sh`.
- Ключ Anthropic теперь можно менять и в админ-панели (хранится в базе зашифрованным).
- Регистрация — по коду приглашения (код знает пользователь, не публиковать).
