# Customs Assistant — правила для Claude

Веб-приложение (FastAPI + SQLite + Jinja2) для таможенного брокера в Грузии: берёт прошлую декларацию
(эталон), оставляет постоянную часть, подставляет товары из новых инвойсов и упаковочных листов,
показывает сравнение «было / стало» и выгружает результат (в том числе в «родной» XML ASYCUDA World).

**Перед работой прочитай [`docs/HANDOFF.md`](docs/HANDOFF.md)** — там текущее состояние, открытые задачи и то,
что известно об ASYCUDA. Устройство проекта подробно — в [`README.md`](README.md).

## Как общаться с пользователем

- По-русски, коротко, пошагово, **без программных терминов** — пользователь не программист.
- Главное правило пользователя — фактическая точность. Не уверен или нет данных — прямо скажи
  «Я не знаю» / «У меня нет точной информации». Ничего не выдумывать.
- Ключи API, пароли, код приглашения — никогда не просить прислать в чат и не выводить.

## Репозиторий публичный

- Не коммитить: ключи, пароли, токены, код приглашения, e-mail, адреса серверов, реальные документы клиентов.
  Для тестов — только обезличенные копии (как `tests/fixtures/asycuda_*.xml`).
- Рабочая ветка — `claude/practical-darwin-sqjl21` (ветка по умолчанию на GitHub — другая, не путать).
- Pull request не создавать, пока пользователь не попросит.
- Не менять файл пользователя `specification_UZ95-039-045-2026.xlsx`.

## Проверки перед каждым коммитом

```bash
pip install -r requirements-dev.txt     # Python 3.11
python -m pytest -q                     # все тесты должны пройти
ruff check .
node --test tests/js/diff.test.mjs
```

## Код

- Каждая строка интерфейса и сообщение об ошибке — через `t()` из `app/i18n.py`, с тремя переводами
  (ru, en, ka). Грузинские тексты требуют проверки носителем языка.
- Модель ИИ не должна угадывать данные: неизвестное — пусто плюс замечание декларанту.
- Схема ответа ИИ (`app/services/wire.py`) — без nullable/union-полей: у Claude API лимит 16 union-параметров
  и 24 необязательных («compiled grammar is too large»). Тест `tests/test_llm.py` следит за лимитами.
